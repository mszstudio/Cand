# C& Project Roadmap

## Completed Phases

- [x] **Phase 1 (v0.1):** Lexer + Parser + AST + LLVM Backend + Native Binary Execution (`cand build` / `cand run`).

## Upcoming Phases

- [ ] **Phase 2 (v0.2):** Complete primitive types, type checker, arithmetic expressions.
- [ ] **Phase 3 (v0.3):** Structs, Enums, Methods, and Control Flow (`if`, `while`, `for`, `match`).
- [ ] **Phase 4 (v0.4):** Module system (`import std.io;`, `export fn`).
- [ ] **Phase 5 (v0.5):** Memory ownership semantics (`owned<T>`, `borrow<T>`, `shared<T>`).
- [ ] **Phase 6 (v0.6):** Error handling (`Result<T, E>`, `Option<T>`, `?` operator).
- [ ] **Phase 7 (v0.7):** Generics and Trait constraints.
- [ ] **Phase 8 (v0.8):** Async/Await & Concurrency primitives (`spawn`, `channel`).
- [ ] **Phase 9 (v0.9):** Compile-time metaprogramming (`comptime`).
- [ ] **Phase 10 (v1.0):** Standard Library (`std/`) and Self-Hosting compiler.
